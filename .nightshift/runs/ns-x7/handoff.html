ns-x7: ns note, an owner-only instruction channel to a running run

Summary

Adds ns note <id> "text", an owner-only command that appends a timestamped note to the new ledger field owner_notes and an owner-note event. The conductor reads unread notes at its between-step checkpoints with ns-conductor owner-notes, follows them over the plan scope, marks them read, and ns report lists them. The guard blocks agents from running it.

Tier T2; p1 took 3 review rounds, p2 took 2. All three boards approved at 608f011. Phase p3 (ADR, changelog, retire plan) was not registered by owner decision and was done directly during integration as ADR 0011.
